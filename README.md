# 3D-RPG
Unity 기반 3D RPG 멀티플레이 게임입니다.  

ScriptableObject와 JSON을 활용해 캐릭터, 아이템, 퀘스트 데이터를 분리 관리했으며,  
Photon을 사용해 멀티플레이 환경을 구현했습니다.  

Firebase를 연동하여 유저 정보와 저장 데이터를 관리하고,  
Jenkins를 활용한 자동 빌드 환경을 구성해 수정 사항 반영 후 빌드 과정을 안정적으로 관리할 수 있도록 했습니다.

## 주요 기능
- 자동 비행 시스템 — 캐릭터가 자동으로 상승하며 목표 거리까지 진행
- 자원 수집 / 판매 시스템 — 진행 거리에 따라 해금되는 자원을 수집하고 골드로 전환
- 성장 업그레이드 시스템 — 이동 속도, 수집 효율, 저장 용량 업그레이드
- 지역 / 도감 해금 — 거리 진행도에 따라 배경과 수집 정보 해금

## 기술적 고민
### 1. 실기기 테스트 중 화면 멈춤 및 재생성 문제 해결
- 에디터에서는 정상적으로 동작했지만, Android 실기기 테스트 중 게임 화면이 멈추거나 다시 열리는 현상이 간헐적으로 발생했습니다.
- `logcat`을 통해 `surfaceDestroyed`, `surfaceCreated` 로그가 반복적으로 발생하는 것을 확인했고, Activity가 재생성되며 게임 화면이 다시 초기화되는 문제로 추정했습니다.
- 이를 해결하기 위해 `AndroidManifest`에 `configChanges` 옵션을 추가하여 화면 회전, 화면 크기 변경 등에 의한 Activity 재생성을 방지하도록 수정했습니다.
- 그 결과 실기기 테스트에서 발생하던 화면 재생성 및 멈춤 현상을 완화했고, Android 플랫폼 이슈를 로그 기반으로 추적하고 대응하는 경험을 얻었습니다.

## 회고
Android 실기기 테스트 중 에디터에서는 발생하지 않던 화면 멈춤 및 재생성 문제가 발생했습니다.  
처음에는 게임 로직 문제로 접근했지만, `logcat`을 통해 `surfaceDestroyed`, `surfaceCreated` 로그를 확인하며 Android Activity 재생성과 관련된 문제로 원인을 좁혀갈 수 있었습니다.

이번 프로젝트를 통해 모바일 개발에서는 에디터 테스트뿐 아니라 실기기 테스트와 로그 분석이 중요하다는 점을 경험했습니다.  
또한 AndroidManifest 설정과 플랫폼 생명주기가 Unity 게임 실행에 영향을 줄 수 있다는 점을 배웠습니다.
