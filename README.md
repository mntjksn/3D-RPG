# 3D-RPG
Unity 기반 3D RPG 멀티플레이 게임입니다.  
Photon을 활용해 멀티플레이 환경을 구현했으며, ScriptableObject와 JSON으로 게임 데이터를 분리 관리했습니다.  
Firebase로 유저 인증 및 데이터 저장을 처리하고, Jenkins 자동 빌드 환경을 구성해 빌드 과정을 안정적으로 관리했습니다.

## 프로젝트 개요
- 개발 환경 : Unity 3D
- 사용 언어 : C#
- 개발 기간 : 2026.02 ~ 2026.04
- 개발 인원 : 1인 (개인 프로젝트)
- 플랫폼 : PC (Window)
- 기술 스택 : Photon PUN2 · Firebase · Jenkins · ScriptableObject · JSON

## 주요 기능
- 플레이어 이동 / 전투 시스템 — 캐릭터 이동, 공격, 몬스터 전투 구현
- NPC / 퀘스트 시스템 — 상점, 업그레이드, 퀘스트 수락 · 진행 · 완료 흐름 구현
- 인벤토리 / 아이템 시스템 — 아이템 획득, 장착, 판매 기능 구현
- 데이터 관리 시스템 — ScriptableObject와 JSON으로 캐릭터, 아이템, 퀘스트 데이터 분리 관리
- Photon 멀티플레이 — 플레이어 생성, 상태 동기화, 몬스터 AI 동기화 구현
- Firebase 저장 시스템 — 유저 인증 및 플레이어 데이터 저장
- Jenkins 자동 빌드 — GitHub Webhook 연동으로 푸시 시 자동 빌드 환경 구성

## 기술적 고민
### 1. Photon 기반 멀티플레이 동기화
- 여러 플레이어가 같은 방에 접속했을 때 플레이어와 몬스터 상태가 동일하게 유지되도록 동기화 구조를 구성했습니다.
- Master Client 기준으로 몬스터 생성과 주요 상태를 관리하고, PhotonView / RPC / RaiseEvent를 활용해 클라이언트 간 상태를 전달했습니다.
- Late Join 상황에서도 기존 게임 상태를 받을 수 있도록 처리하여 참가자 입장 후 상태 차이를 줄였습니다.
### 2. ScriptableObject / JSON 기반 데이터 구조 설계
- 캐릭터, 아이템, 퀘스트 데이터가 코드에 직접 묶이지 않도록 ScriptableObject와 JSON으로 데이터를 분리했습니다.
- 정적 게임 데이터는 ScriptableObject로, 유저 진행 상태와 저장 데이터는 JSON으로 구분하여 관리했습니다.
- 데이터와 로직을 분리함으로써 새로운 아이템이나 퀘스트 추가 시 코드 수정 부담을 줄였습니다.
### 3. 3D 환경 성능 최적화
- 오브젝트와 이펙트가 늘어나면서 발생하는 렌더링 부하를 줄이기 위해 최적화를 진행했습니다.
- Object Pool, Static 설정, Occlusion Culling, LOD, Sprite Atlas를 적용해 불필요한 렌더링 비용을 절감했습니다.
- Profiler로 성능 병목 구간을 확인하며 3D 환경에서 안정적인 플레이가 가능하도록 개선했습니다.

## 회고
### 주요 어려움
  #### 1. 멀티플레이 동기화 기준 설계
  - 플레이어마다 상태가 다르게 보이는 문제가 반복 발생했고, 어느 클라이언트를 기준으로 상태를 관리해야 하는지 판단하는 것이 어려웠습니다.
  - Master Client 기준으로 주요 상태를 관리하는 구조로 정리하면서 해결할 수 있었습니다.
  #### 2. Late Join 처리
  - 게임 도중 입장한 플레이어에게 현재 상태를 어떻게 전달할지 구조를 여러 번 수정하면서 해결했습니다.
  #### 3. 3D 환경 성능 문제
  - 오브젝트가 늘어날수록 프레임이 떨어지는 문제가 발생했고, Profiler로 병목 구간을 확인하며 하나씩 개선해 나갔습니다.
### 배운 점
- 멀티플레이에서는 기능보다 동기화 기준을 먼저 설계하는 것이 중요하다는 것을 배웠습니다.
- Profiler를 활용하면서 성능 문제는 측정 먼저, 최적화 나중 순서가 맞다는 것을 직접 경험했습니다.
- ScriptableObject와 JSON으로 데이터를 분리하면서 확장에 유리한 구조 설계의 중요성을 느꼈습니다.
- Jenkins 자동 빌드를 구성하면서 반복 작업을 자동화하는 것의 실질적인 가치를 경험했습니다.
